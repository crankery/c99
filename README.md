# Mini Mini Cortex 

***Note: Do not build this thing, I am just experimenting.***

Just a silly project really. Trying to squeeze Stuart Conner's [Mini Cortex](https://www.stuartconner.me.uk/mini_cortex/mini_cortex.htm) down
to a smaller form factor. Really, for no good reason.

I am going to attempt to add a different storage mechanism as CF cards are a bit hard to work with these days. To this end, there's an expansion
connector on this thing which is intended to have a stack of expansions plugged in from below.
